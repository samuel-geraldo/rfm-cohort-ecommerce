# Sumber Data

File `online_retail_II.xlsx` tidak disertakan di repo ini (lihat `.gitignore`).

- Dataset: UCI Online Retail II
- Sumber: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Rentang: Desember 2009 – Desember 2011
- Jumlah baris: ~1 juta
- **Catatan:** file punya dua sheet (satu per rentang tahun). Wajib baca dengan
  `sheet_name=None` lalu concat, kalau tidak separuh data hilang tanpa error.

Cara pakai: unduh file `.xlsx` dari link di atas, taruh di folder ini dengan nama
`online_retail_II.xlsx`.
